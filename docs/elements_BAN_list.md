# the words or elements DO NOT USE in the repo

本文件是这类禁用项的**唯一来源**。`CLAUDE.md` 的 `banned-words` 条目指向这里，不再自己维护一份。
看到新词就说一声，往表里加一行。

## lists

  |禁用|改用|
  |---|---|
  |契约|`约定`/`接口约定` / `字段约定`|
  |§|**`DO NOT USE`**|
  |漂移|`UNKNOWN`|

## 注意

- 上面这些词是**仓库拥有者不会写的词**。出现即说明是 agent 自己造的，而且会自我复制（文档、commit message、agent 笔记都会跟着用），所以看到就替换，不要保留原文。
- `§` 的唯一例外：`src/third_party/` 下那 4 处是上游 RFC 的章节引用，属于子模块原文，**不要动**。
- 引用章节写 `7.4 节` 或裸编号 `7.4`。
- 发现此文档更新时，应**禁止**的内容应**立即更新**
