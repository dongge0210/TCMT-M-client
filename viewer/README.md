# TCMT Viewer

纯展示页面：只从 tcmt-server 读取数据（REST + WebSocket），不含任何业务、
存储或采集逻辑。

## 使用

推荐由 server 托管（零配置）：

```bash
cd ../server && node server.js
# 本机浏览器打开 http://127.0.0.1:8080/
# 其他设备浏览器打开 http://<server-ip>:8080/ （server 默认监听 0.0.0.0）
```

也可以直接双击 `index.html` 本地打开，页面会自动回退到
`http://127.0.0.1:8080` 请求数据（server 已开 CORS）。

## 功能

- 多设备总览：所有接入设备同屏显示（在线状态 / CPU / 内存 / GPU / 温度），
  实时更新（WebSocket 每 0.5s 推送设备列表 + 快照）
- 点击设备卡片或下拉框切换详情；详情区（仪表 / 传感器 / 历史）跟随选中设备
- server 开了 `--auth-token` 时，首次访问会弹出输入框，令牌存 localStorage，
  之后所有 REST/WS 请求自动携带
- CPU / 内存 / GPU 环形仪表 + 温度 + 迷你趋势
- 运动传感器（加速度 / 角速度 / 屏幕开合角 / 采样率）
- 温度列表、传感器字段索引（当前 / 最小 / 最大）
- 历史曲线：字段下拉选择，2s 轮询 + 自动刷新

纯前端实现（原生 HTML/CSS/JS，无构建、无依赖）。
